# X1C Operator Course

Interactive training course for new robotics team members on the team's six Bambu Lab X1C printers. It covers 3D printing from zero, Fusion export, Bambu Studio, printing from microSD, the AMS, supports, practice labs, troubleshooting, a final exam and a mentor sign-off.

**Live site:** served by GitHub Pages from `index.html`.

## Files

| File | What it is |
|---|---|
| `index.html` | The site. Generated, so don't edit it by hand. |
| `x1c-operator-course.html` | The editable source. |
| `build.sh` | Regenerates `index.html` from the source. Run it after every edit, then commit both. |

## Notes

- Progress (lesson checks, exam score, sign-off) is saved in each student's own browser. Students send their record to a lead with the **Copy completion record** button.
- Shared shop photos only work in the Claude-hosted version of the course. On this site, the troubleshooting drawings show and the photo spots stay hidden.
- Team training material. Not affiliated with or endorsed by Bambu Lab.
